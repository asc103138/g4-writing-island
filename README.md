## 🏝️ 專案特色

1. **起承轉合 3D 微縮主題島嶼**：
   - 🏝️ **起之島**：月考倒數與書房苦讀之島（紅瓦書房、大書桌、堆積如山課本、倒數鐘樓）。
   - 🏫 **承之島**：考場鐘聲與神態之島（古典校舍、大銅鐘、整齊課桌椅、雪白試卷、黑板）。
   - ⚡ **轉之島**：驚天動地與家庭風暴之島（客廳小屋、憤怒黑雷雲與金色閃電、滿江紅巨型考卷雕像）。
   - 🌅 **合之島**：超越自我與朝陽之島（超越之門神殿、第一名大金盃、百科全書螺旋天梯、金色風車）。
   - 🐲 **守門神殿**：文字饕餮守門巨獸（八角祭壇、起承轉合四筆圖騰柱、四格漫畫金色魔鏡）。
2. **教師逐段批改雙軌印章機制**：
   - 支援通關密碼（預設 `888`）或一鍵切換巡堂免密碼模式。
   - 具備「💯 甲上 / 🌟 優等 / 👍 佳作」三款紅印章動畫與快捷退件標籤。
3. **守門獸審查與四格漫畫生成**：
   - 嚴格紅線攔截口語非書面語。
   - 劇情矛盾偵測（考前貪玩卻考滿分觸發「裂痕警報」與破裂網點）。
   - 純前端全自動校園 Q 版四格漫畫向量渲染與學習單匯出。
4. **真實 20x20 國小作文稿紙謄寫專區**：
   - 首行空兩格、標點獨立佔格，供學生看著螢幕端正謄寫至作文簿。
