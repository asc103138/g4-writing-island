# RDQ 需求規格卡：《我最○○的人》3D 微縮模型紋理與細節優化

## 一段式需求規格
針對 [`ocean-writing-adventure/index.html`](file:///Users/tunyuan/Library/CloudStorage/GoogleDrive-asc103138@st.tc.edu.tw/%E6%88%91%E7%9A%84%E9%9B%B2%E7%AB%AF%E7%A1%AC%E7%A2%9F/115%E5%9B%9B%E4%B8%8A%E4%BD%9C%E6%96%87/ocean-writing-adventure/index.html) 的 6 張設計藍圖場景（**深海峽谷全景**＋**第 0～4 站潛水站**），採用「**極致繪本細節**」標準進行程序化 `CanvasTexture` 法線/凹凸紋理、幾何細節與環境微動畫升級；**採逐站精修節奏**，每完成 1 張設計圖的實機優化即以無頭瀏覽器截圖對照驗收，確認通過後再進入下一站，並維持 0 Console Errors/Warnings 與零 CORS 規範。

## ✅ 已確認需求與納入項目
1. **推進節奏**：逐站精修（① 深海峽谷全景 → ② 第 0 站 → ③ 第 1 站 → ④ 第 2 站 → ⑤ 第 3 站 → ⑥ 第 4 站大白鯊聖殿），每站截圖對照確認。
2. **質感標準**：極致繪本細節（高細分法線凹凸貼圖、多層發光珊瑚、水波焦散光網）。
3. **全域與基座升級**：
   - 海底砂地波紋與**動態水波焦散光網動畫**。
   - 六角玄武岩峽谷峭壁＋36 條直槽基座加上**岩石凹凸紋理、漸層與發光青苔斑塊**。
   - 玻璃穹頂加上**細緻金屬肋條鉚釘與微弱水面高光反射**。
   - 潛水站下方改為**反重力磁浮科技基地**（拔除粗大落地石柱）：銀白／鈦灰流線金屬環形底盤（含散熱柵／指示燈）、底部錐形能量艙＋旋轉雙層渦輪環＋向下青藍噴流光束，並於海床正下方配置發光磁浮錨點陣列；站間引導點同步升級為科技浮標信標。
   - **深海生物互動微動畫**：水母觸手飄動、珍珠貝微幅開合呼吸、沉船氣泡柱上升。
4. **各站專屬核心細節**：
   - **一體成型繪本雕塑基準（全站適用）**：以 `LatheGeometry` 與 `TubeGeometry` 曲線掃掠取代直線幾何拼湊，移除建築生硬黑邊外框（`addComicOutline`），採用溫潤霧面烤漆漸層＋細微樹脂顆粒，並於建築與砂地交界加鋪圓潤卵石／貝殼過渡；珊瑚與海帶全面升級為彎曲有機管狀珊瑚與寬葉波浪海帶。
   - **第 0 站（起）**：一體成型旋削觀察艙＋平滑嵌合氣密門與觀景窗＋彎管潛望鏡＋縮小 40% 繫船柱，調整三位 NPC 構圖比例。
   - **第 1 站（承）**：海龜立體隆起六角龜甲片＋黃金放大鏡真實半透明玻璃鏡片。
   - **第 2 站（轉）**：沉船木板釘紋、甲板欄杆與船舵細節＋氣泡柱與金幣散落。
   - **第 3 站（合）**：巨蚌珍珠母貝虹彩光澤＋微幅呼吸開合動畫＋燈塔光感。
   - **第 4 站（終點）**：大白鯊「波塞頓」平滑漸層皮膚、聖殿大理石紋、水晶內部切面光澤。

## ❓ 假設清單（黃燈預設，若有異議請於確認時指出）
- **優化順序預設**：由外而內、由起點到終點，第 1 步先優化「**深海峽谷下潛全景 + 潛水站共用基座與玻璃穹頂**」，再依序第 0 → 1 → 2 → 3 → 4 站。
- **效能底線假設**：仍保留 `PCFSoftShadowMap` (`1024×1024`) 與貼圖快取復用，避免無上限增加 Draw Calls 導致一般筆電掉幀。
- **貼圖技術假設**：全部高階紋理（岩石法線、焦散光網、珍珠母貝、木板釘紋、大理石紋）皆透過程式動態生成 `CanvasTexture`／`bumpMap`／`roughnessMap`，不引入外部圖片 URL。
