# RDQ 需求規格：四年級《考試前後》作文導引與四格漫畫守門獸 3D 島嶼

## 一句話任務
打造單頁全內嵌 3D 沉浸式互動島嶼（起承轉合四島＋四格漫畫守門獸），嚴格整合四上期末教材句型、教師雙軌批改印章鎖定、真實稿紙抄寫模擬、守門獸裂痕警報與全自動 Q 版四格漫畫生成，並在系統沉澱雙層造島技能。

## ✅ 已確認
- **教學主題與教材核心**：題目為**《考試前後》**，依據 **`115學年度四上作文.pdf` 第三單元**，包含寫作引導、寫作指南（誇飾放大法與縮小法）、寫作大綱（起承轉合）、佳作欣賞範文（Ⅰ）
- **教師逐段批改雙軌印章機制**：每座島嶼段落完成後，設有專屬**「教師批改面板」**。預設支援教師通關密碼（預設密碼 `888`，可自訂），亦可一鍵切換為免密碼巡堂快速點擊模式。提供「💯 甲上 / 🌟 優等 / 👍 佳作」三款紅印章動畫；若不合格，教師可勾選快捷退件標籤（字數不足 / 缺少誇飾 / 錯別字 / 語意不通），段落鎖定並浮現紅筆批註，經核准後方能點亮島嶼燈塔解鎖航道（Ⅲ）
- **國小真實作文稿紙格子抄寫模擬**：四段作文通過守門獸生成四格漫畫後，除了四格漫畫排版，完整呈現**「國小標準綠格真實稿紙模擬專區」**（一字一格、段落開頭自動空兩格、標點符號標準佔格與不落行首規範、可切換字級大小），供學生端正抄寫至作文簿（Ⅲ）
- **單頁全內嵌架構**：比照 **`g4-society-island/unit3`**，採單一 HTML 檔案交付（HTML + CSS + JS 內嵌，Three.js 走 CDN importmap），零建置、本機點兩下即開、支援 GitHub Pages 部署（Ⅲ）
- **相機平滑 Fly-To 運鏡**：點選島嶼時相機平滑飛入俯瞰該島並展開面板；完成段落並經教師批改後拉回全景，點亮島嶼燈塔並解鎖通往下一島的航道（Ⅲ）
- **技能缺口補足方案**：雙層沉澱——建立底層通用 **`learning-island-builder`** 技能，並擴充寫作專屬模板 **`g4-writing-island-builder`**（Ⅲ）
- **純前端 SVG 漫畫引擎與獨立匯出**：採校園 Q 版四格漫畫風格，完全由作文段落自動驅動分鏡與對話，支援學生自選表情包微調，並可一鍵獨立匯出向量 SVG 或高解析度 PNG（Ⅲ、Ⅳ）
- **入島三檔自主定向**：小書精靈引導學生選擇「初探者」（低成就拼圖）、「挑戰者」（中成情報骨架）、「大師」（高成就開放挑戰），全程最適鷹架導引（Ⅲ）
- **分級審查與容錯保護**：初探者完成拼圖即 100% 通關保護成就感；中成就嚴格檢查前後情節連貫；高成就加碼審查修辭深度並解鎖金色特效框（Ⅲ）
- **四上佳作同儕觀摩小卡**：側邊提供「點我看四年級同學怎麼寫這一句」微縮提示卡（Ⅳ）
- **教材審查與嚴格紅線攔截**：守門獸審查時，若出現未符四上教材語法、口語流行語（如「超廢/完蛋」）或非書面語，**嚴格標紅退回**，強制引導替換為教材語彙後始得放行（Ⅲ）
- **五大教材核心句型積木**：各島嶼嵌入五大專屬句型（①比…還…；②連…都比…；③原本…頓時變得…；④熬過了…接下來迎接的是…；⑤經過這次…我一定要…）供學生直接組裝套用（Ⅲ）
- **四上期末「好詞替換小幫手」**：建置口語-教材對照表（如：很緊張→如坐針氈/冷汗直流；很害怕→草木皆兵/心驚膽戰；很多卷子→堆積如山/重點比芝麻還多），支援一鍵替換（Ⅳ）
- **CLT 認知負荷嚴格依循**：任務說明字數 ≤ 60 字，工作記憶元素控制在 3~4 塊內，畫面聚焦單一操作動作，鷹架選項控制在 3~4 個內（Ⅲ）
- **退回島嶼之三步修正鷹架**：若段落情節衝突或結構不足，守門獸啟動**「三步精準導引」**（① 指出具體問題；② 召喚教材佳作錦囊；③ 提供句型替換積木）（Ⅲ）
- **守門獸審查與「裂痕警報」**：情節衝突格打上**漫畫破裂網點與大問號**，守門獸吐槽並一鍵傳送回該島進行三步修正（Ⅲ）
- **輔助寫作工具**：內建**「四年級字數靈力計量條」**（50-80字/段動態能量回饋）與**「四上期末翰林國語課文好詞百寶箱」**（Ⅲ、Ⅳ）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- **暫存機制** → 預設支援瀏覽器 `localStorage` 自動保存學生的段落草稿、教師批改狀態與漫畫設定，避免刷新頁面後遺失
- **在地情境融滲** → 預設在誇飾法句型庫中貼心加入梧棲海線在地譬喻（如「考卷發下時，心跳比高美濕地的風車轉得還快」）

## ➕ 已採納（象限Ⅳ）
- **教師批改蓋章彈窗**：提供教師密碼/快捷點擊蓋章核准（甲上、優等、佳作印章動畫與退件標籤）
- **稿紙格式全文抄寫版面**：專為國小作文簿抄寫設計，一字一格、首行空兩格、標點規範佔格、可切換字體大小
- **單頁式獨立 HTML 交付**：比照 `g4-society-island`，單一 HTML 檔案包含所有邏輯，零外部依賴、雙擊可開、支援離線教學
- **學習單與漫畫雙重匯出**：支援一鍵匯出「四段作文全文＋四格漫畫」學習單，並可單獨匯出四格漫畫高解析 PNG/SVG
- **沉澱專屬雙層技能**：建立 **`learning-island-builder`** 與 **`g4-writing-island-builder`** 技能規範
- **自選四上四格表情包**：漫畫格子提供表情替換面板，增加學生寫作動機
- **四上期末好詞替換小幫手**：口語一鍵替換為四上期末教材書面好詞
- **四上期末翰林好詞百寶箱**：整合四上課文詞彙庫，提供學生即時點選套用
- **四上佳作同儕觀摩小卡**：提供 micro-prompt 觀摩卡，激發學生用詞靈感
- **段落字數靈力計量條**：以遊戲能量條直觀回饋 50-80 字達成率

## ❌ 排除項（明確不做）
- 未經教師批改蓋章核准前，學生不得自行解鎖下一座島嶼
- 不允許任何非四上教材之網路流行口語或超綱詞彙（第一階紅線嚴格攔截）
- 不對低成就學生進行嚴苛的情節深度審查（完成拼圖即保證通關獲取成就感）
- 不串接付費商業生圖 API（避免學生在教室因網路或額度限制中斷體驗）
- 不採用需繁複打包建置的繁瑣工程結構（維持單一 HTML 零配置優勢）

## 📋 一段式需求規格
為臺中市國小四年級學生打造一套以 **`115學年度四上作文.pdf` 第三單元《考試前後》** 為核心的 3D 沉浸式微縮寫作與四格漫畫學習島嶼。系統以單頁獨立 HTML 格式交付（架構嚴格比照 **`g4-society-island/unit3`**，Three.js 走 CDN importmap），建構「起、承、轉、合」四座主題微縮島嶼與終點「四格漫畫守門獸」，配備平滑 Fly-To 相機運鏡。學生入島時自主選擇「初探者、挑戰者、大師」三檔難度，各島嶼嚴格遵守 CLT 認知負荷標準（說明 ≤ 60 字），配備「四上期末好詞替換小幫手」、「同儕觀摩小卡」與五大核心教材句型積木。系統設有**「教師逐段批改雙軌印章機制」**，每段完成後需經教師通關密碼或巡堂快速蓋章認證方能解鎖下一座島嶼；終點守門獸落實紅線審查與矛盾「裂痕警報」，通過後純前端自動生成校園 Q 版四格漫畫。通關時不僅提供四格漫畫與學習單匯出，更完整呈現符合國小作文簿規範的**「真實綠格稿紙全文抄寫專區」**供學生謄寫，且同步沉澱 **`learning-island-builder`** 與 **`g4-writing-island-builder`** 技能規範。
