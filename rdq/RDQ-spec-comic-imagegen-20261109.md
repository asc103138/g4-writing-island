# RDQ 需求規格卡：四格漫畫即時 AI 生圖與誇飾特效連動模組

## 一句話任務
在四年級《考試前後》3D 寫作冒險島嶼中，串接即時 AI 生圖 API（支援 Gemini Imagen / 本地安全 Key 輸入），以「校園逗趣 Q 版彩色日漫風」將學生創作的四段作文自動轉譯為提示詞生成四格漫畫，並深度連動教材誇飾修辭特效，同時具備離線向量備援機制。

## ✅ 已確認需求
- **生圖執行機制（A1）**：
  - 串接即時 AI 生圖 API（預設支援 Google Gemini / Imagen API）。
  - 前端提供「🔑 教師 API Key 安全設定面板」，金鑰僅暫存於當前瀏覽器 `localStorage`，絕不寫入原始碼、絕不 commit 至公開 GitHub Repo（嚴格遵循資安紅線）。
  - 當學生通過守門神獸審查時，觸發「即時生成四格漫畫」流程（附帶生動的「神獸繪製中…」載入動態）。
- **視覺風格定義（A2）**：
  - **校園逗趣 Q 版彩色日漫風**：四格畫面統一採用大眼萌系、誇張表情（滿頭冷汗、燃燒怒火、眼冒金星）、動態速度線與生動對白框。
  - 四格畫面結構對應教材大綱：
    - 第 1 格【起】：書房內被如山作業包圍、咬牙夜讀。
    - 第 2 格【承】：考場鐘聲響起、雪白考卷飄落、大腦當機空白。
    - 第 3 格【轉】：講臺領考卷滿江紅、回家媽媽氣得火冒三丈使出降龍十八掌。
    - 第 4 格【合】：痛定思痛、按部就班複習、迎向勝利超越自我。
- **誇飾修辭深度連動（A3）**：
  - 系統自動解析學生段落中的誇飾關鍵詞，動態注入生圖提示詞（Prompt Engineering）與前置特效：
    - 偵測到「比包青天還黑」→ 提示詞強調「face turned pitch-black like Justice Bao, hilarious exaggeration」。
    - 偵測到「降龍十八掌 / 火冒三丈」→ 提示詞強調「fiery angry mom with blazing dragon palm comic aura」。
    - 偵測到「大腦當機 / 刷的一聲全空白」→ 提示詞強調「robotic brain glitch smoke, blank mind anime expression」。
- **高可用備援機制（Fallback）**：
  - 若未設定 API Key、斷網、或生圖 API 額度用盡，系統自動無縫降級為「純前端 Q 版向量漫畫」，確保教室課堂教學 100% 順暢不中斷。

## ❓ 假設（預設值）
- **生圖模型與尺寸**：預設採用 1:1 正方形比例（或橫向 4:3），符合四格漫畫排版。
- **提示詞自動翻譯**：前端直接將學生的四段教材文字轉譯為中英雙語最佳化 Prompt，確保 Q 版漫畫人物角色造型前後四格一致（同一位國小四年級學生主角）。

## ❌ 排除項（明確不做）
- 絕不將任何 API Key 寫死在前端原始碼或提交至 GitHub。
- 不讓學生因為生圖等待而卡住後續的稿紙謄寫區（謄寫稿紙始終即時呈現）。

## ✔ 驗收條件
- [ ] 守門獸神殿新增「🔑 生圖 API 設定」按鈕（輸入 Gemini API Key，支援一鍵測試連線）。
- [ ] 審查通過後，四格漫畫可一鍵呼叫 AI 生圖，依序生成四格「校園逗趣 Q 版彩色日漫風」圖片。
- [ ] 自動識別段落中「比包青天還黑」、「降龍十八掌」、「大腦當機」等誇飾關鍵詞並轉化為專屬提示詞特效。
- [ ] 未填 Key 或生成失敗時，維持純前端向量漫畫正常顯示（雙軌容錯）。
- [ ] 產生的四格漫畫支援下載或匯出高解析圖檔。
